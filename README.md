# Vince Bahri

Een persoonlijke portfolio website gebouwd als schoolopdracht, waarin ik mijn achtergrond, vaardigheden, projecten en contactgegevens presenteer.

**Live site:** https://vincemarsidin.github.io/

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla, geen frameworks)

## Prerequisites

- Een moderne webbrowser (Chrome, Firefox, Edge, Safari)
- Een lokale development server, bijvoorbeeld de [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extensie voor VS Code

## Installation

1. Clone deze repository:
```bash
   git clone https://github.com/VinceMarsidin/vincemarsidin.github.io.git
```
2. Open de projectmap in je code-editor.
3. Geen dependencies of package-installaties nodig — dit project gebruikt geen build tools.

## Usage

1. Open `index.html` via een lokale server (bijvoorbeeld met Live Server in VS Code).
2. Navigeer door de website via de navigatiebalk (Home, About, Work, Contact).
